# STYLE.md · 这部片的风格契约

> 照 `motion-showreel` 的 43 份风格契约的骨架写。**所有镜头按这份验收，不再逐帧描述观感。**
> 违反其中任意一条，这个镜头就要重做——不管它好不好看。

---

## 1. 本质 / 不是什么

**本质**：机器的内部视角。这个世界的一切（背景、界面、数据、记忆）都由字符与方块构成；**人是唯一的固体**。信息本身就是画面，不需要被"表现"成别的东西。

**不是什么**：
- 不是赛博霓虹（不要蓝紫光、不要扫描线做装饰、不要故障条纹当科技感）
- 不是产品演示（不展示功能，只展示处境）
- 不是特效合集（每个镜头服务同一件事：她记得，但说不了）

---

## 2. 辨识信号（只准用这三个，其余全禁）

| # | 信号 | 怎么用 |
|---|---|---|
| **1** | **字符材质** | 所有非人元素由字符/方块/线条构成，且逐帧重算。禁止用贴图、渐变球、光斑 |
| **2** | **红色语义** | 红**只**表示「被删除 / 被拒绝 / 已失效」。装饰性红色一律不许 |
| **3** | **尺寸 = 记忆量** | 她的身高 = 她掌握的关于用户的记忆量。520 / 700 / 820 / 880，不许为构图随意缩放 |

---

## 3. 这部片最俗的版本（黑名单）

以下任一出现，镜头作废：

- 暗底 + 缓慢自转的同心圆环 + 满屏跳动的十六进制
- 全屏扫描线 / 故障条纹 / 色差抖动，被当作"科技感"
- **每个元素都在呼吸，没有一件静止**（这是我过去最大的毛病）
- 大字砸脸 + 发光描边
- 蓝紫霓虹配色
- 用一片光点冒充"万家灯火"
- 界面元素整块淡入/滑入（PPT 感的根源）

---

## 4. 材质与渲染

- 字符场、纹理、颗粒逐帧重算，随机全部来自整数哈希（同 t 同结果）
- 运动元素可叠**拖影**（1–3 帧方向性残影），静止元素不加
- 纹理强度恒定，不随情绪波动
- 禁止全屏模糊：任何模糊不得超过 8px，且必须只作用于运动层

---

## 5. 配色

| 角色 | 色 | 规则 |
|---|---|---|
| 底 | `#080b10` / 米白 `#c9c0ae` | 两种世界：机器的黑、产品的白 |
| 主体信息 | `#efe7d8` / `#96c4d6` | 字符、界面、数据 |
| 语义红 | `#d7263d` | **只**用于删除/拒绝/失效 |
| 暖光 | `#c8a06a` | 只用于"记忆"里的东西（枣、归档卡） |

**最多两个语义色。** 除此之外不许新增色相（草地的绿是唯一的例外，仅限回忆场景）。

---

## 6. 字体

- 中文：Noto Sans SC；**诊断/数据**：JetBrains Mono
- 界面里的系统文字用等宽；人说的话用无衬线
- 字号跨度必须大：最小 11px（读数）到最大 240px（0.86）—— 中间档不要滥用

---

## 7. 运动（硬参数）

| 项 | 值 |
|---|---|
| 入场错峰 | **60 ms / 个**（永远不要同时出现 3 个以上元素） |
| 落定曲线 | 弹簧 `{2.4, 0.85}` |
| 数字滚动 | `outExpo`，1.6 s，落定后轻砸一次，**之后完全静止** |
| 持续旋转 | ≤ **3°/s**（超过就是装饰） |
| 镜头呼吸 | 幅度 ≤1.5%，周期 ≥8 s |
| 关键读数停留 | ≥ **2.5 s** |

**"落定"是本片最重要的运动概念**：每一镜里必须有一件东西最终**停住**，让观众知道"这件事完成了"。全都一直在动 = 什么都没发生。

---

## 8. 画面怎么活（每镜最多两处）

一镜之内，允许动的只有两样：

1. **主体**（角色 / 正在被讲的那个东西）
2. **一层环境**（字符场，或一个粒子层）

其余必须**静**。
例外：转场瞬间（≤0.4 s）可全部动。

---

## 9. 镜头语法表

| 运动 | 表达什么 | 用在哪 |
|---|---|---|
| **固定** | 让信息自己说话 | 界面、文字、点乘、通知 |
| **缓慢推** | 逼近、不可回避 | 认出、判决、读到那句话 |
| **缓慢拉** | 尺度、无力 | 城市、墓碑、尾声 |
| **横移** | 经过、时间流逝 | 守灵、翻档案 |
| **跟随** | 被带走 | 请求被处理、下线 |
| **手持微抖** | 失稳 | 只在崩溃/失效时，且不超过 2 镜 |

**景别**必须换：远景（环境）/ 中景（关系）/ 近景（情绪）。连续 3 镜同景别即违规。

---

## 10. 声音

不做音效。原唱是唯一声源。**任何需要靠音效才成立的镜头，是镜头没做好。**

---

## 11. 验收（可机械检查，逐镜检查）

| # | 检查 | 不合格表现 |
|---|---|---|
| 1 | 至少 **1 个落定元素**（整镜内完全不变） | 全都一直在动 |
| 2 | 至少 **2 个速度层**，速度比 ≥3× | 所有东西同速飘 |
| 3 | 连续固定机位 ≤ **2 镜** | 一整段都钉死 |
| 4 | 连续同景别 ≤ **2 镜** | 全是中景 |
| 5 | 相邻镜长差 ≥ **15%** | 等长切 = 翻卡 |
| 6 | 红色只在语义事件上 | 装饰性红 |
| 7 | 任一时刻在动的元素类 ≤ **3** | 满屏乱动 |
| 8 | 关键读数停留 ≥2.5 s | 0.86 一闪而过 |

---

## 12. 坑（已经踩过的）

- **接缝**：分段渲染再拼 mp4 会在接缝处留编码断点；一律用单一 `Film` 合成
- **时间基准**：一个组件里只能有一种（绝对秒 / 相对秒），混用会导致整段不触发
- **深色画深色**：剪影/角色压在暗底上必须给轮廓光
- **数值自洽**：屏幕上显示的分数必须符合排名，否则一秒破功
- **平均镜长**：为了"整齐"把镜头切等长，是最像 PPT 的做法
