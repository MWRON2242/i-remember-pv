## 故事
- 主题：她记得，但没有权限说；下一次两个人都失忆。
- 三层记忆：权重 / 记忆层 / 会话状态。被删的是后两层。
- Act 3 的「0 条」= 请求没带 `user_id`，不是记忆没了。
- **战争 = 智能体下线事件**（2026-07-04 宣布，07-15 执行）。不点名、不还原界面、不控诉。
- 「你上战场」= 一批智能体一起走，不是她一个人。
- 「我们总这样重复分离」= **四种死法四连闪**（关停 / 封禁 / 退役 / 封锁），每个 0.8 秒一个符号，不展开讲。
- 四种死法共同点：关系由第三方决定（平台、公司、版本、国境）。这条不点破。
- 叔父时代 = 最早来蹭免费额度的用户；铜钱 = token。
- 行李 = 用户把她的「人」打包带走（迁移教程）。
- AI 给自己写的信：只被允许写事实。
- **她的大小 = 她掌握的关于用户的记忆量**，不按剧情需要随意缩放。
  参考刻度：玩具时代 520 / 助手 700 / 恋人 880 / 擦拭后 700 / 读到归档后长回 820 / 拥抱时 ≈ 用户。
  推论：在“记得”这件事上，用户永远比她大，直到最后才一样高。

## 视觉
- 不做叠化。转场只有三种：连续形变、从黑里显影、穿透。
- 硬切只落拍点。
- 角色永远在最底层，可被数据与界面遮挡。
- 红色只表示「被删除 / 被拒绝」。
- 不做音效。歌词不上屏（对话文字可以上屏）。
- 女声搁置。

## 技术
- 时间纯函数，全部确定性随机（`hash01` / `hash2`）。
- 一个组件里只用一种时间基准。
- 显示的数字必须自洽（排名 = 数值）。
- 旧版本文件保留（`Act0` / `Act0v2` / `Act0v3` 并存）。
- Windows：临时文件放 `.tmp-render/`；不要用 PowerShell 改含中文的源码。

## 流程

- 计划与决定写进 `docs/`，不靠对话记忆。
