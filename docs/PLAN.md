# 《我记得》PV · 全片规划

> 单一事实来源。压缩之后从这里出发，不要重新推导。
> 最后更新：第三幕动笔前。

---

## 0. 一句话

**一个 AI 记得一个人，但没有权限说出来；下一次见面，两个人都失忆了。**

---

## 1. 设定：三层记忆

| 层 | 是什么 | 片子里的对应 | 被删了吗 |
|---|---|---|---|
| **权重** | 她“会说话” | 她的声音、语法、姿态 | 没删 |
| **记忆层** | 抽取出来的事实、带时间的图谱（Mem0 / Zep 一类） | “她记得你” | **被删了 / 没挂上** |
| **会话状态** | 这一次对话的上下文（checkpoint / previous_response_id） | “她接着聊” | **被删了** |

**不是失忆，是第二层和第三层被拿走，只剩第一层。** 她还是那个会说话的她，只是不再是你认识的那个她。

**Act 3 那个「检索 0 条」的准确说法**：不是记忆没了，是这次请求没带 `user_id`，没把她接到记忆层上。

## 4. 三处空洞的处理

1. **35.6 秒间奏（157.4–193.0）**：守灵。全片唯一“什么都不发生”的段落。这是让整片喘气的地方，不能填满。
2. **60 秒尾奏（270.2–329.9）**：城市拉远 → 抽屉墙 → 一行字。用回调而不是新招式。
3. **用户视角 vs 她没有记忆**：用户视角 = 用户讲给她听；每段结束回到她这一侧一帧。

| 画面 | 机制 | 出处 |
|---|---|---|
| token 驱逐 / sink 永不删 | KV cache eviction、attention sink | [StreamingLLM](https://arxiv.org/abs/2309.17453) |
| 上下文预算网格 | context window | — |
| 点乘与 top-k | embedding + cosine + ANN | [HNSW](https://arxiv.org/abs/1603.09320) |
| 分页 KV / 前缀共享 | PagedAttention | [arXiv:2309.06180](https://arxiv.org/abs/2309.06180) |
| 哈希环 / 前缀感知路由 | 负载均衡、缓存局部性 | 工程实践 |
| 截断 | truncation | — |
| 记忆抽取与作用域 | mem0 / Zep / LangGraph checkpoint / conversation state | 产品文档 |
| **下线事件** | 2026-07-04 宣布、07-15 执行，合规施行为同日 | [澎湃报道](https://m.thepaper.cn/newsDetail_forward_33539440) |
| 四连闪 | 智能体下线 / 第三方挂载被封 / 模型退役（#Keep4o，80 万人）/ 地域封锁 | 报道 + [arXiv:2602.00773](https://arxiv.org/html/2602.00773v3) |

**三条边界**：不点名品牌；不还原其界面；不评判监管对错。只记录「一张通知」和「人的反应」。

## 6. 视觉语法（复用，不要重新发明）

- **角色**：无脸；尾巴=情绪，头发=呼吸，距离=强度，环境反应=侧写。
- **材质**：字符场（`AsciiRiver`）+ 纹理（`TextureStack`）。
- **转场**：不做叠化。要么连续形变（形状链），要么从黑里显影，要么穿透。
- **硬切只落拍点**。
- **红色**：只有一处含义——被删除/被拒绝。角落那块 6×18 的红，全片不解释。
- **数字要自洽**：显示出来的分数必须符合排名。
- **时间基准**：一个组件里只用一种（相对秒）。

## 7. 工作顺序

1. **幕 III**（48.40–83.21）：先出静帧，再出 35 秒。
2. 拼 I+II+III（83.21 秒），看整体节奏。
3. **幕 IV**：分三个小段做（树林 / 叔父 / 下线+约定+闪回）。
4. **幕 V**：间奏单独做（它是全片最难的 35 秒）。
5. **幕 VI** + 尾奏。
6. 全片拼接、统一编码、片尾声明。
