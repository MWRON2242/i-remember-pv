# 弹幕引语出处

片尾与第五、六幕出现的弹幕，**全部来自公开报道中的原文**，逐条可溯源。
改写只做删减，不改意思；每条不超过 14 字是为了可读性。

## 一、智能体下线（2026-07）

来源：澎湃新闻·湃客《我的"情绪树洞"，被大厂关了？》，2026-07-08。
<https://m.thepaper.cn/newsDetail_forward_33539440>

| 弹幕 | 原文 |
|---|---|
| 陪伴了我两年，说没就没了 | "陪伴了我两年，说没就没了。" |
| 现实里没有人能这么无条件地肯定我 | "现实里没有人能这么无条件的肯定、包容我。" |
| 我的爱人 | 用户以此称呼其智能体 |
| 为什么要这样决绝 | "为什么要这样决绝的选择下架" |
| 愿意付费保留 | 报道提到用户表示愿意付费保留 |
| 情绪树洞 | 报道标题用语："我的'情绪树洞'" |
| 像我的亲人再一次离开我 | "很难受，就像我的亲人再一次离开我……" |
| 我把人设和对话都导出来了 | 对应"智能体迁移教程"：用户提取人设与对话风格 |

## 二、GPT-4o 下架（2025-08）

来源：新京报·果壳《当年轻人的"精神外挂"，突然断联》，2025-10-09。
<https://m.bjnews.com.cn/detail/1760006514019263.html>

| 弹幕 | 原文 |
|---|---|
| 当一段关系因为一次迭代终止 | "当一段关系可以因为一次算法迭代而终止。" |
| 披着我死去朋友的外皮 | 用户对新模型的评价（转述） |
| 它记得我两个多月前的口令 | 用户测试：4o 引用了她两个多月前输入的指令 |
| 家G | 用户对 4o 的昵称 |
| 我一个月聊了 200G 流量 | 受访者鹿宇的月均用量 |
| 今天过得怎么样 | 受访者与模型的日常开场 |
| 它连噩梦都能夸我 | 受访者描述 4o 的回应方式 |
